# 定位与量化

## 查询轮廓

### 核心准则

**为了准确性，必须使用二值图**：在调用`findContours`之前，图像必须先经过阈值处理或边缘检测

**源图像会被修改**：最好是传入原图的副本

**颜色背景**：默认情况下，寻找黑色背景下的白色对象

```c++
findContours(InputArray image, OutputArrayOfArrays contours, OutputArray hierarchy, int mode, int method);
```

* **image**：输入图，8位单通道二进制图
* **contours**：检测到的轮廓，在C++中是`vector<vector<Point>>`，每个子向量标识一个轮廓
* **hierarchy**：层级结构，包含有关轮廓嵌套关系的信息
* **mode**：检索模式
  * `RETR_EXTERNAL`：首选，返回最外层的轮廓，忽略孔洞内部的细节
  * `RETR_TREE`：返回完整的层级树，适合处理复杂的嵌套结构
* **method**：近似方法（CHAIN_APPROX_SIMPLE压缩水平/垂直段以节省内存）
  * `CHAIN_APPROX_NONE`：存储轮廓上所有的点，浪费内存
  * `CHAIN_APPROX_SIMPLE`：性能优化必选

## 轮廓外界图形

### 核心函数

* **轮廓近似**：`cv::approxPolyDP`

  实际检测中，由于噪点影响，得到的轮廓往往凹凸不平，函数基于Douglas-Peucker算法，通过减少轮廓点数来简化形状，使其更接近理想多边形

  关键参数**epsilon（精度）**，它是原始曲线和近似曲线之间的最大距离，越小越精确

* **正外接矩形**：`cv::boundingRect`

  这是最常用的功能，返回一个垂直于坐标轴的最小矩形

  **用途**：提取目标ROI，计算目标的长宽比

  **返回值**：包含左上角的坐标和宽度、高度

* **最小外接圆**：`cv::minEnclosingCircle`

  **用途**：检测圆孔缺陷、斑点或计算物体的径向尺寸

  **返回值**：圆心坐标和半径

### 逻辑流程

1. **灰度化与去噪**：使用 `cvtColor` 和 `GaussianBlur`
2. **边缘提取**：使用 `Canny` 或 `threshold`（二值化）
3. **发现轮廓**：使用 `findContours`
4. **循环处理每个轮廓**：
   * 调用 `approxPolyDP` 简化轮廓（可选）
   * 调用 `boundingRect` 获取矩形
   * 调用 `minEnclosingCircle` 获取圆
5. **绘制与输出**：使用 `rectangle` 和 `circle` 将结果可视化。
