## 图像滤波

### 卷积概念

一幅图像通过滤波器得到另一幅图像
其中滤波器又称为**卷积核**，滤波的过程成为**卷积**

卷积核一般是奇数，一方面是增加padding的原因，另一方面是保证锚点在中间，防止位置发生偏移的原因

在深度学习中，**卷积核越大，看到的信息（感受野）越多，提取的特征越好，同时计算量也就越大**

当卷积核大于1且不进行边界扩充，输出尺寸将相应缩小

当卷积核以标准方式进行边界扩充，则输出数据的空间尺寸将与输入相同

> 边界扩充计算公式
>
> **N = (W - F + 2P) / S + 1**
>
> * N，输出图像大小
> * W，源图大小；F，卷积核大小；P，扩充尺寸
> * S，步长大小

### 高通滤波和低通滤波

低通滤波表示在某个阈值以下可以通过

高通滤波表示在某个阈值以上可以通过

**低通滤波可以去除噪音或平滑图像**

**高通滤波可以帮助查找图像的边缘**

### 图像卷积

```c++
CV_EXPORTS_W void filter2D( InputArray src, OutputArray dst, int ddepth,
                           InputArray kernel, Point anchor = Point(-1,-1),
                           double delta = 0, int borderType = BORDER_DEFAULT );
```

`int ddepth`：经过卷积之后的位深，-1表示按照输入位深

`InputArray kernel`：卷积核

`Point anchor`：卷积核锚点中心点

`double delta`：卷积之后元素会加上这个值，默认值自动找

`int borderType`：边界类型

**示例代码**

```c++
int filter2DTest() {
    cv::VideoCapture cap(0, cv::CAP_ANY);
    if (!cap.isOpened()) {
        std::cout << "Error opening video stream or file" << std::endl;
        return -1;
    }

    cv::Mat frame;
    cap >> frame;
    if (frame.empty()) {
        std::cout << "Error reading frame" << std::endl;
        return -1;
    }
    cv::imshow("origin frame", frame);

    // 生成卷积核
    cv::Mat kernel = cv::Mat::ones(5, 5, CV_32F) / 25;
    // 执行卷积流程
    cv::Mat frameBlur;
    cv::filter2D(frame, frameBlur, -1, kernel);

    cv::imshow("frame blur", frameBlur);
    cv::waitKey(0);

    return 0;
}
```

### 方盒滤波和均值滤波

方盒滤波卷积核k等于a乘以全是1的矩阵

`normalize` = true时，a = 1 / W * H（均值滤波）

`normalize` = false时，a = 1

```c++
// 方盒滤波
CV_EXPORTS_W void boxFilter( InputArray src, OutputArray dst, int ddepth,
                            Size ksize, Point anchor = Point(-1,-1),
                            bool normalize = true,
                            int borderType = BORDER_DEFAULT );
// 均值滤波
CV_EXPORTS_W void blur( InputArray src, OutputArray dst,
                       Size ksize, Point anchor = Point(-1,-1),
                       int borderType = BORDER_DEFAULT );
```

`Size ksize`：卷积核的大小

### 高斯滤波

高斯滤波，两边低中间高，锚点的比重是最大的

```c++
CV_EXPORTS_W void GaussianBlur( InputArray src, OutputArray dst, Size ksize,
                               double sigmaX, double sigmaY = 0,
                               int borderType = BORDER_DEFAULT );
```

`double sigmaX`：离锚点的x方向延展距离

`double sigmaY`：离锚点的y方向延展距离

**推荐kSize取(0, 0)，通过修改sigma调整**

**示例代码**

```c++
int GaussianBlurTest() {
    cv::VideoCapture cap(0, cv::CAP_ANY);
    if (!cap.isOpened()) {
        std::cout << "Error opening video stream or file" << std::endl;
        return -1;
    }

    cv::Mat frame;
    cap >> frame;
    if (frame.empty()) {
        std::cout << "Error reading frame" << std::endl;
        return -1;
    }
    cv::imshow("origin frame", frame);

    // 生成卷积核
    cv::Mat frameBlur;
    cv::GaussianBlur(frame, frameBlur, cv::Size(3, 3), 1, 1);

    cv::imshow("frame blur", frameBlur);
    cv::waitKey(0);

    return 0;
}
```

### Sobel算子

1. 先对x方向求导
2. 然后对y方向求导
3. 最终结果：`|G| = |Gx| + |Gy|`

```C++
CV_EXPORTS_W void Sobel( InputArray src, OutputArray dst, int ddepth,
                         int dx, int dy, int ksize = 3,
                         double scale = 1, double delta = 0,
                         int borderType = BORDER_DEFAULT );
```

`int dx`：对x求导，得到y的边缘

`int dy`：对y求导，得到x的边缘

`int ksize`：卷积核大小，如果改为-1，就是Scharr算子

`double scale`：将结果进行缩放

**示例代码**

```c++
int sobelTest() {
    // 从文件中获取图片
    cv::Mat frame = cv::imread("D:/Download/1.png", cv::IMREAD_GRAYSCALE);
    cv::Mat blurredFrame;
    cv::medianBlur(frame, blurredFrame, 3);
    cv::Mat normalizedFrame;
    cv::normalize(blurredFrame, normalizedFrame, 0, 255, cv::NORM_MINMAX, CV_8U);
    cv::imshow("frame", normalizedFrame);

    // 生成卷积核
    cv::Mat frameBlur;
    cv::Sobel(frame, frameBlur, CV_16S, 0, 1, 3);

    cv::imshow("frame blur", frameBlur);
    cv::waitKey(0);

    return 0;
}
```

### Scharr算子

Scharr只能求x方向或y方向的边缘


### Canny边缘检测算法

1. 使用5*5高斯滤波消除噪声
2. 计算图像梯度的方向（0deg/45deg/90deg/135deg）
3. 取局部最大值
4. 阈值计算

```c++
CV_EXPORTS_W void Canny( InputArray image, OutputArray edges,
                        double threshold1, double threshold2,
                        int apertureSize = 3, bool L2gradient = false );
```
