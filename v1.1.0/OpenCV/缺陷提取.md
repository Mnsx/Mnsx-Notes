# 缺陷提取

## 阈值操作

### 基本阈值操作

阈值操作是最简单的图像分割方法，通过比较像素值与一个预设的阈值，将图像划分为前景和背景

核心函数：`cv::threshold`

```shell
dst(x, y) = threshold(src(x, y), thresh, maxval, type)
```

五种标准阈值类型

* **二进制阈值**

  **逻辑**：像素值高于阈值，设为maxval，否则设为0

* **反二进制阈值**

  **逻辑**：高于阈值设为0，低于阈值设为maxval，适合寻找深色缺陷

* **截断阈值**

  **逻辑**：高于阈值的像素被削平为阈值，低于阈值的保持不变

* **取零阈值**

  **逻辑**：低于阈值的像素直接变黑，高于阈值的保持原样

* **反取零阈值**

  **逻辑**：高于阈值的全变黑，低于阈值的保持原样

### 大津法（自动寻找阈值）

**原理**：它会自动分析图像的直方图，寻找两个峰值（前景和背景）之间的黄金分割点，使得两类像素的类内方差最小

**用法**：在type参数后面加上`| THRESH_OTSU`并将thresh参数设为0

```c++
threshold(src, dst, 0, 255, THRESH_BINARY | THRESH_OTSU);
```

### 实战总结

| **任务描述**               | **推荐写法**        | **理由**                                         |
| -------------------------- | ------------------- | ------------------------------------------------ |
| **检测亮背景下的深色划痕** | `THRESH_BINARY_INV` | 划痕变白（255），背景变黑（0），方便后续找轮廓。 |
| **环境光照经常变化**       | `THRESH_OTSU`       | 算法自动计算阈值，鲁棒性极高。                   |
| **只想保留高亮区域**       | `THRESH_TOZERO`     | 过滤掉所有暗部杂质，只留下发光点。               |

## 直方图均衡化

### 直方图

直方图是图像中像素强度分布的统计图，横轴代表亮度级别（0-255），纵轴代表拥有该亮度的像素数量

### 直方图均衡化目标

如果一张图的直方图都挤在中间（低对比度），均衡化会通过一个映射函数，将这些像素分布拉伸到整个0-255的范围，其结果是原本暗的地方更暗，亮的地方更亮

```c++
equalizeHist(src, dst);
```

* **输入**：必须是8位单通道图像（灰度图）
* **输出**：均衡化后的灰度图
