# 工厂方法模式

Facotry Method就是把**创建对象**的行为交给子类决定，而不是在代码中直接new

## 需要工厂方法模式的原因

```c++
class Button {};
Button * btn = new Button();
```

代码依赖具体类`Button`如果后续需要变更为`WindowsButton`，需要大幅修改代码

## 简易实现

### 抽象产品

```c++
class Product {
public:
    virtual void use() = 0; // 纯虚函数要求子类必须实现
    virtual ~Product() = default;
};
```

### 具体产品

```c++
class ProductA : public Product {
public:
    void use() override {
        cout << "A" << endl;
    }
};

class ProductB : public Product {
public:
    void use() override {
        cout << "B" << endl;
    }
};
```

### 抽象工厂

```c++
class Creator {
public:
    virtual Product * createProduct() = 0;
}
```

### 具体工厂

```c++
class CreatorA : public Creator {
public:
    Product * createProduct() override {
        return new ProductA();
    }
};

class CreatorB : public Creator {
public:
    Product * createProduct() override {
        return new ProductB();
    }
}
```
