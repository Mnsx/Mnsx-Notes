# 命令模式

Command就是把一个请求封装成一个对象，从而可以用不同的请求对客户端进行参数化，并支持撤销、队列、日志等操作

## 需要命令模式的原因

如果有个按钮功能

```c++
button.onClick() {
    light.turnOn();
}
```

这样会导致Button和Light强耦合

如果需要添加其他功能，需要修改Button代码

## 简易实现

### Command接口

```c++
class Command {
public:
    virtual void execute() = 0;
};
```

### Receive

```c++
class Light {
public:
    void turnOn() {
        cout << "Light ON" << endl;
    }
};
```

### ConcreteCommand

```c++
class LightOnCommand : public Command {
private:
    Light * light;
public:
    LightOnCommand(Light * l) : light(1) {}
    void execute() override {
        light->turnOn();
    }
};
```

### Invoker

```c++
class Button {
private:
    Command * command;
public:
    void setCommand(Command * cmd) : command(cmd) {}
    void click() {
        command->execute();
    }
}
```
