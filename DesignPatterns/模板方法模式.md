# 模板方法模式

Template Method就是在基类中定义算法的整体流程，但是把某些步骤延迟到子类实现

## 需要模板方法模式的原因

假设算法流程，有5个步骤，其中第1个和第5个是固定的，然后第2个和第3个是由不同子类实现的

如果每个算法子类都写完整的算法流程，那么就会导致代码重复

## 简易实现

### 抽象类

```c++
class AbstractClass {
public:
    void templateMethod() {
        step1();
        step2();
        step3();
        step4();
    }
protected:
    void step1() {
        cout << "1" << endl;
    }
    virtual void step2() = 0;
    virtual void step3() = 0;
    void step4() {
        cout << "4" << endl;
    }
};
```

### 子类实现

* ConcreteClassA

  ```c++
  class ConcreteClassA : public AbstractClass {
  protected:
      void step2() override {
          cout << "A step2" << endl;
      }
      void step3() override {
          cout << "A step3" << endl;
      }
  };
  ```

* ConcreteClassB

  ```c++
  class ConcreteClassB : public AbstractClass {
  protected:
      void step2() override {
          cout << "B step2" << endl;
      }
      void step3() override {
          cout << "B step3" << endl;
      }
  }；
  ```

## 模板方法模式和策略模式区别
