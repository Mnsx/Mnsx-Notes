# 适配器模式

Adapter就是把一个类的接口转换成客户端期望的接口，使本来不兼容的类可以一起工作

## 需要适配器模式的原因

如果需要一个接口

```c++
class Target {
public:
    virtual void request() = 0;
};
```

但是需要使用的类是

```c++
class Adaptee {
public:
    void specificRequest() {
        cout << "special request" << endl;
    }
};
```

## 简易实现

### Target

```c++
class Target {
public:
    virtual void request() = 0;
};
```

### Adatpee

```c++
class Adaptee {
public:
    void specificRequest() {
        cout << "special request" << endl;
    }
};
```

### Adapter

```c++
class Adapter : public Target {
private:
    Adaptee * adaptee;
public:
    Adapter(Adapter * a) : adaptee(a) {}
    void request() override {
        adaptee->specificReqeust();
    }
};
```

## 两种Adapter实现方式

* **对象适配器**

  使用组合，**这是最常用方式**

* **类适配器**

  使用**多继承**

  ```c++
  class Adapter : public Target, public Adaptee
  ```
