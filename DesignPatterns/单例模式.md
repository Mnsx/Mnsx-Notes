# 单例模式

单例类只会生成一个实例，初始化行为仅在该类被加载时进行一次，因为单例类的**构造函数是`private`的**，所以无法是从外部代码中调用构造函数

## MeyersSingleton（线程安全）

```c++
class Singleton {

private:
    // 私有构造函数
    Singleton() {}
    // 禁止复制构造函数和赋值操作符
    Singleton(const Singleton &) = delete;
    Singleton & operator=(const Singleton &) = delete;
    
public:
    // 暴露静态接口获取唯一实例
    static Singleton & getInstance() {
        
        static Singleton instance; // C++11线程安全
        return instance;
    }
};
```

* **线程安全（C++11保证）**
* **懒加载**
* 不用手动释放
* 实现简单

> C++11后增加了对**函数内静态变量初始化**的语义保证
>
> 在第一次调用`getInstance`时程序会自动生成
>
> ```c++
> if (instance_not_initialized) {
>     lock();
>     if (instance_not_initialized) {
>         construct instance
>     }
>     unlock();
> }
> return instance;
> ```
>
> **并且只有在第一次调用时**

## 饿汉式单例（程序启动时创建）

```c++
class Singleton {
    
private:
    Singleton() {}
    static Singleton instance;
    
public:
    static Singleton & getInstance() {
        
        return instance;
    }
};
```

* **程序启动时创建**
* **线程安全**

## 懒汉式（带锁）

```c++
class Singleton {
    
private:
    Singleton() {}
    
    static Singleton * instance;
    static std::mutex mtx;

public:
    static Singleton * getInstance() {
        
        std::lock_guard<std::mutex> lock(mtx);
      	if (instance == nullptr) {
            
            instance = new Singleton();
        }
        return instance;
    }
};
Singleton * Singleton::instance = nullptr;
std::mutex Singleton::mtx;
```

* **每次调用都要加锁**
* **性能差**
