# 观察者模式

Ovserver就是定义对象之间的一对多依赖关系，当一个对象状态改变，所有依赖对象都会自动收到通知

## 需要观察者模式的原因

在一个天气系统中，如果温度发生变化，则需要获取温度的，手机APP、网页、显示屏都需要变化

```c++
app.update();
web.update();
screen.update();
...
```

温度类依赖太多对象，耦合严重

## 简易实现

### 观察者接口

```c++
class Observer {
public:
    virtual void update(int value) = 0;
    virtual ~Observer() = default;
};
```

### 被观察者

```c++
class Subject {
private:
    vector<Observer *> observers;
    int state;
public:
    void attach(Observer * obs) {
        observers.push_back(obs);
    }
    void notify() {
        for (auto obs : observers) {
            obs->update(state);
        }
    }
    void setState(int s) {
        state = s;
        notify();
    }
}
```

### 具体观察者

```c++
class ConcreteObserverA : public Observer {
public:
    void update(int value) override {
        cout << "ObserverA: " << value << endl;
    }
};

class ConcreteObserverB : public Observer {
public:
    void update(int value) override {
        cout << "ObserverB: " << value << endl;
    }
}
```

## 观察者模式进阶写法

```c++
class Subject {
private:
    vector<function<void(int)>> observers;
public:
    void subscribe(funciton<void(int)> f) {
        observers.push_back(f);
    }
    
    void notify(int v) {
        for (auto & f : ovservers) {
            f(v);
        }
    }
};
```
