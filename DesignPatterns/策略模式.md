# 策略模式

Strategy就是把一组算法封装成不同策略，并且可以在运行时自由切换

## 需要策略模式的原因

```c++
void sort(vector<int> & data, int type) {
    if (type == 1) {
        quickSort(data);
    } else if (type == 2) {
        mergeSort(data);
    } ...
}
```

随着新增加排序算法，if/else越来越多，代码难以维护

## 简易实现

### 抽象策略

```c++
class Strategy {
public:
    virtual void execute() = 0;
    virtual ~Strategy() = default;
};
```

### 具体策略

* StrategyA

  ```c++
  class ConcreteStrategyA : public Strategy {
  public:
      void execute() override {
          cout << "Strategy A" << endl;
      }
  };
  ```

* StrategyB

  ```c++
  class ConcreteStrategyB : public Strategy {
  public:
      void execute() override {
          cout << "Strategy B" << endl;
      }
  };
  ```

### Context（使用策略的类）

```c++
class Context {
private:
    Strategy * strategy;
public:
    Context(Strategy * s) : strategy(s) {}
    void run() {
        strategy->execute();
    }
}
```

## 策略模式进阶写法

```c++
#include <functional>

class context {
private:
    function<void()> strategy;
public:
    Context(function<void()> s) : strategy(s) {}
    
    void run() {
        strategy();
    }
}
```
