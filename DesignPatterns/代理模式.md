# 代理模式

Proxy就是为另一个对象提供一个**替身**，通过这个替身控制原对象的访问

## 需要代理模式的原因

在加载图片时，例如从磁盘读取，加载图片很慢

```c++
Image img("test.png");
img.display();
```

## 简易实现

### 抽象接口

```c++
class Image {
public:
    virtual void display() = 0;
    virtual ~Image() = default;
}
```

### 真实对象

```c++
class RealImage : public Image {
private:
    string filename;
public:
    RealImage(const string & name) : filname(name) {
        cout << "Loading image: " << filename << endl;
    }
    
    void display() override {
        cout << "Displya image: " << filename << endl;
    }
};
```

### 代理对象

```c++
class ProxyImage : public Image {
private:
    string filename;
    RealImage * realImage = nullptr;
public:
    ProxyImage(const string & name) : filename(name) {}
```
