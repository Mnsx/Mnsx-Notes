# 排序

## 选择排序

```c++
void selectedSort(int n, int * arr) {

        for (int i = 0; i < n - 1; ++i) {

                int max = i;
                for (int j = i + 1; j < n; ++j) {

                        if (arr[max] < arr[j]) {

                                max = j;
                        }
                }
                if (max != i) {

                        int temp = arr[max];
                        arr[max] = arr[i];
                        arr[i] = temp;
                }
        }
}
```

## 快速排序

1. 选择一个元素，这个元素被称为**基准值**
2. 将容器分区为，**大于基准值、基准值、小于基准值**
3. 继续对两个分区的**无序容器**进行排序

```c++
int partition(int * arr, int left, int right) {

        int point = arr[left];
        int i = left, j = right;

        while (i < j) {

                while (i < j && arr[j] >= point) {

                        j--;
                }
                while (i < j && arr[j] <= point) {

                        i++;
                }
                if (i < j) {

                        int temp = arr[i];
                        arr[i] = arr[j];
                        arr[j] = temp;
                }
        }

        int temp = arr[left];
        arr[left] = arr[i];
        arr[i] = temp;

        return i;
}

void quickSort(int * arr, int left, int right) {

        if (left < right) {

                int pos = partition(arr, left, right);
                quickSort(arr, left, pos - 1);
                quickSort(arr, pos + 1, right);
        }
}
```
