# 图

## 狄克斯特拉算法

1. 找出**权值最小**的节点，即可在最短时间额你到达的节点
2. 更新该节点的邻居开销
3. 重复这个过程，知道对图中的每个节点都完成了更新
4. 计算最终的路径

狄克斯特拉算法**只适用于有向无环图**，并且也不能处理含有**负权边**的情况

### 代码实现

实现这个算法需要使用三个散列表

* 第一个用来存储每个节点包括的所有邻居以及从这个节点到邻居节点所需的权值
* 第二个用来存储每个节点的开销，指的是从起始节点到这个节点的最少开销
* 第三个用来存储当前节点的父节点信息

最后还需要一个数组，用来记录处理过的节点

```c++
class Solution {
public:
    vector<string> getLowPath(unordered_map<string, unordered_map<string, int>> graph, string start, string end) {

        unordered_map<string, int> costs; // 最小花费
        unordered_map<string, string> parents; // 父节点
        unordered_map<string, bool> processed; // 是否处理过
        
        // 所有cost无穷大，parent=null
        for (auto & node : graph) {
            
            string key = node.first;
            costs[key] = INT_MAX;
            parents[key] = "";
            processed[key] = false;
        }
        
        // 起点cost为0
        costs[start] = 0;
        
        while (true) {
            
            // 找到未处理 & 花费最小的节点
            string minNode = "";
            int minCost = INT_MAX;
            
            for (auto & costPair : costs) {
                
                string node = costPair.first;
                int cost = costPair.second;
                
                if (!processed[node] && cost < minCost) {
                    
                    minCost = cost;
                    minNode = node;
                }
            }
            
            // 如果找不到未被处理的节点退出
            if (minNode == "") {
                
                break;
            }
            
            processed[minNode] = true;
            
            // 更新邻居的cost和parent
            for (auto & neighbor : graph[minNode]) {
                
                string to = neighbor.first;
                int weight = neighbor.second;
                
                // 更新路径
                if (costs[to] > costs[minNode] + weight) {
                    
                    costs[to] = costs[minNode] + weight;
                    parents[to] = minNode;
                }
            }
        }
        
        vector<string> res;
        string cur = end;
        
        while (!cur.empty()) {
            res.push_back(cur);
            cur = parents[cur]; 
        }
        
        return res;
    }
};
```
