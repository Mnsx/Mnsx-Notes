# 概念

## 大O表示法

大O表示法，指出算法**运行时间的增量**

大O表示法指出的是**最坏情况**下的运行时间

常见的大O运行时间

* `O(log n)`，对数时间
* `O(n)`，线性时间
* `O(n * log n)`
* `O(n^2)`
* `O(n!)`，乘阶时间

在大O表示法`O(n)`中，n实际上指的是`c * n`，c是算法所需的固定时间量

## 递归

每个递归函数都有两部分，**基线条件（base case）**和**递归条件（recursive case）**

递归条件指的是函数调用自己，而基线条件则是函数跳出递归，避免形成无限循环

## 分而治之

分而治之的工作原理在于

* 找出**简单**的基线条件
* **确定如何缩小问题的规模**，使其符合基线条件
