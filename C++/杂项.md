# 杂项

## 标准程序库

C++98列入的C++标准程序库

* **STL（Standard Template Library，标准模板库）**，覆盖容器、迭代器、算法、函数对象、各种容器适配器和函数对象适配器

* **iostream**，覆盖用户自定缓冲功能，国际化I/O以及预先定义好的对象`cin`，`cout`，`cerr`和`clog`

* **国际化支持**，包含多区域能力，`wchat_t`和`wstring`等类型都是对促进Unicode有所帮助

* **数值处理**，包括复数模板和纯数值模板

* **异常阶层体系**，包括`base class exception`及其派生类`logic_error`和`runtime_error`以及更深继承的类

* **C89标准库**，1989C标准程序库内的每个东西也都被覆盖于C++内

TR1详细叙述了14个新组件，统统都放在`std`命名空间中，更正确的说法是在其嵌套命名空间tr1内

* **智能指针`tr1::shared_ptr`和`tr1::weak_ptr`**

  前者的作用与内置指针相同，但是存在引用计数，当这个引用计数为0时，就会删除这个对象，**但是无法避免环状引用的问题**

  `trl::weak_ptr`没有引用计数，当最后一个指向某个对象的`shared_ptr`被销毁后，纵使还有`tr1::weak_ptr`指向同一对象，该对象仍会被删除

* **`tr1::function`**

  此物得以表示任何函数或函数对象，只要其签名符合目标

  ```c++
  void registerCallback(tr1::funciton<string (int)> func);
  ```

* **`tr1::bind`**

  能够作为STL绑定器，`tr1::bind`可以和`const`及`non-const`成员函数协作运作，可以和`by-reference`参数协作，**`tr1::bind`是第二代绑定工具**
