# 杂项

## 标准程序库

C++98列入的C++标准程序库

* **STL（Standard Template Library，标准模板库）**，覆盖容器、迭代器、算法、函数对象、各种容器适配器和函数对象适配器

* **iostream**，覆盖用户自定缓冲功能，国际化I/O以及预先定义好的对象`cin`，`cout`，`cerr`和`clog`

* **国际化支持**，包含多区域能力，`wchat_t`和`wstring`等类型都是对促进Unicode有所帮助

* **数值处理**，包括复数模板和纯数值模板

* **异常阶层体系**，包括`base class exception`及其派生类`logic_error`和`runtime_error`以及更深继承的类

* **C89标准库**，1989C标准程序库内的每个东西也都被覆盖于C++内

TR1详细叙述了14个新组件，统统都放在`std`命名空间中，更正确的说法是在其嵌套命名空间tr1内

* **智能指针`tr1::shared_ptr`和`tr1::weak_ptr`**

  前者的作用与内置指针相同，但是存在引用计数，当这个引用计数为0时，就会删除这个对象，**但是无法避免环状引用的问题**

  `trl::weak_ptr`没有引用计数，当最后一个指向某个对象的`shared_ptr`被销毁后，纵使还有`tr1::weak_ptr`指向同一对象，该对象仍会被删除

* **`tr1::function`**

  此物得以表示任何函数或函数对象，只要其签名符合目标

  ```c++
  void registerCallback(tr1::funciton<string (int)> func);
  ```

* **`tr1::bind`**

  能够作为STL绑定器，`tr1::bind`可以和`const`及`non-const`成员函数协作运作，可以和`by-reference`参数协作，**`tr1::bind`是第二代绑定工具**

## 按值传递

对于同时需要接收左值和右值的函数，可以使用按值传递

通常需要解决，同时需要处理左值和右值的情况，可以通过声明两个函数来解决

```c++
class Widget {
public:
    void addName(const std::string& newName) {
        names.push_back(newName);
    }
    void addName(const std::string&& newName) {
        names.push_back(std::move(newName));
    }
};
```

但是上述的解决方法不免有点麻烦，因为需要写两份代码，两份注释，两份文档，所以还可以使用模板方法

```c++
class Widget {
public:
    template <typename T>
    void addName(T&& newName) {
        names.push_back(std::forward(newName));
    }
};
```

但是使用模板方法也有弊端，就是他必须在头文件中定义，而且他可能会产生很多的具化方法

那么这种情况下可以选择使用按值传递

```c++
class Widget {
public:
    void addName(std::string newName) {
        names.push_back(std::move(newName));
    }
};
```

因为是按值传递，所以newName移动操作，不会对调用方产生影响，而且这是newName最后一次调用，所以可以直接使用std::move对它操作

对比三种方式的成本开销

* **重载**

  无论传入左值还是右值，调用方的实参都会绑定到名字为newName的引用上，而这样都不会在复制或移动时产生任何成本，所以成本合计：对于左值一次复制，对于右值一次移动

* **使用万能引用**

  与重载相同，调用方实参都会绑定到newName的引用上，无成本的操作，由于使用了完美转发，左值会复制，右值会移动，所以成本合计：左值对一个一次复制，右值对应一次移动

* **按值传递**

  无论传入左值还是右值，针对形参都会进行一次构造，如果是左值进行复制构造，如果是右值进行移动构造，而内部都是将newName移动，所以成本合计：左值是一个次复制加一次移动，右值是两次移动
