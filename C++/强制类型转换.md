# 强制类型转换

C++除了能使用C中的强制类型转换外，还新增了四种强制类型转换：`static_cast`、`dynamic_cast`、`const_cast`、`reinterpret_cast`，**主要运用于继承关系类间的强制转化**

## static_cast

相当于传统的C的强制类型转换，该运算符把`expression`转换为`new_type`类型，用来强迫隐式转换

**`static_cast`不能转换掉`expression`的`const`、`volatile`、`_unaligned`属性**

## dynamic_cast

```c++
dynamic_cast<type *>(e);
dynamic_cast<type &>(e);
dynamic_cast<type &&>(e);
```

type必须是一个类类型，必须是一个有效指针类型、左值或者右值类型

如果一条`dynamic_cast`语句的转换目标是指针类型并且失败了，则会返回0

如果转换目标是引用类型并且失败了，则会抛出一个`std::bad_cast`异常

并且`dynamic_cast`在对于下行转换时，具有类型检查，比较`static_cast`更加安全

## const_cast

用于修改类型的const或volatile属性

1. 常量指针被转化成非常量的指针，并且仍然指向原来的对象；
2. 常量引用被转换成非常量的引用，并且仍然指向原来的对象；
3. `const_cast`一般用于修改底指针。如const char *p形式

## reinterpret_cast

`new_type`必须是**一个指针、引用、算术类型、函数指针或者成员指针**，它可以把一个指针转换成一个整数，`reinterpret_cast`意图执行低级转型，实际动作可能取决于编辑器，这也就表示它不能够移植

**底层二进制重解释，极其不安全**
