# 迭代器

## 设计简单的List迭代器

迭代器是一种行为类似指针的对象，指针中包括内容提领和成员访问，而**迭代器最重要的工作正是对`operator*`和`operator->`的重载工作**

```c++
template <typename T>
class List {
public:
    void insert_front(T value);
    void insert_end(T value);
    void display(std::ostream & os = std::cout) const;
private:
    ListItem<T> * _end;
    ListItem<T> * _front;
    long _size;
};

template <typename T>
class ListItem {
public:
    T value() const {
        return _value;
    }
    ListItem * next() const {
        return _next;
    }
 	...
private:
    T _value;
    ListItem * _next;
};
```

上述是简写的List容器，如果需要将自定义的List带入STL库带有的函数中，需要设计迭代器

```C++
template <class Item>
// 此迭代器为链表服务
struct ListIter {
    Item * ptr; // 用来保持和容器之间的联系
    ListIter(Item * p = 0) : ptr(p) {}
    Item & operator*() const {
        return *ptr;;
    }
    Iterm & operator->() const {
        return ptr;
    }
    ListIter & operator++() {
        ptr = ptr->next();;
        return * this;
    }
    ListIter operator++(int) {
        ListIter tmp = * this;
        ++*this;
        return temp;
    }
    bool operator==(const ListIter & i) const {
        return ptr == i.ptr;
    }
    bool operator!=(const ListIter & i) const {
        return ptr != i.ptr;        
    }
};
```

## 迭代器的分类

根据移动特性和施行操作，迭代器可以分为五类

* **Input Iterator**：这种迭代器所指向的对象，不允许外界改变，**只读**
* **Output Iterator**：**只写**
* **Forward Iterator**：**允许写入型算法**，在这种迭代器所形成的区间上进行读写操作
* **Bidirectional Iterator**：**可双向移动**
* **Random Access Iterator**：这种覆盖**所有指针算法能力**

## Traits编程技法

迭代器所指对象的类型称为该迭代器的value type

如果value 唐渝鹏必须用于函数的返回值，使用模板参数推导机制就无法实现了

```C++
template <class T>
struct MyIter {
	 // 内嵌类型声明
    typedef T value_type;
    T * ptr;
    MyITer(T * p = 0) : ptr(p) {}
    T & operator*() const {
        return * ptr;
    }
    ...
};

template <class I>
typename I::value_type func(I ite) {
    return * ite;
}
```

`func()`返回值类型必须加上关键字`typename`，因为T是一个模板参数，编译器不知道`MyIter<T>::value_type`代表一个类型，**`typename`用于告诉编译器这是一个类型，才能通过编译**

上述办法通过声明内嵌类型尝试解决将value_type作为返回值的问题，但是**如果不是class type，就无法定义内嵌类型**

```c++
template <class I>
struct iterator_traits {
    typedef typename I::value_type value_type;
};
```

这个traits的意义在于，如果I类定义有自己的value type，那么就可以通过`I::value_type`萃取出来，则

```C++
template <class I>
typename iterator_traits<I>::value_type func(I ite) {
    return *ite;
}
```

根据这个特性，可以为`traits`提供特花版

```C++
template <class T>
struct iterator_traits<T *> {
    typedef T value_type;
};
```

于是对于没有class type的类型，可以通过这个特化版，提取处value type

同样的应该对`const`类型的变量也提供一个特化版，用来返回`non-const`的value type

```c++
template <class T>
struct iterator_traits<const T *> {
    typedef T value_types;
};
```

在`traits`中最常用的就是下面五个

```c++
template <class T>
struct iterator_traite {
    typedef typename I::iterator_category iterator_category;
    typedef typename I::value_type value_type;
    typedef typename I::defference_type defference_type;
    typedef typename I::pointer pointer;
    typedef typename I::reference reference;
}
```

### difference type

difference type用来表示两个迭代器之间的距离，因此可以用来表示容器的最大容量

```c++
template <class I, class T>
typename iterator_traits<I>::difference_type count(I first, I last, const T & value) {
    typename Iterator_traits<T>::difference_type n = 0;
    for ( ; first != last; ++first) {
        if (*first == value) {
            ++n;
        }
    }
    return n;
}
```

针对特殊类型的difference type特化版有两个，其中其实用**c++内建的`ptrdeff_t`作为原生指针的difference type**

```c++
template <class I>
struct iterator_traits { 		typedef typename I::difference_type defference_type;
};

template <class T>
struct iterator_traits<T *> {
    ...
    typedef ptrdiff_t difference_type;
};

template <class T>
struct iterator_traits<const T *> {
    ...
    typedef ptrdeff_t difference_type;
};
```

### reference type & pointer type

对一个允许改变所指对象值内容的迭代器进行提领操作时，获取的应该是左值，如果需要传回左值

```c++
template <class I>
struct iterator_traits {
    typedef typename I::pointer pointer;
    typedef typename I::reference reference;
};

template <class I>
struct iterator_traits<T *> {
    typedef T * pointer;
    typedef T & reference;
};
template <class I>
struct iterator_traits<const T *> {
    typedef const T * pointer;
    typedef const T & reference;
};
```

### iterator_category

SGI声明了五个结构体来表示五种迭代器类型

```C++
struct input_iterator_tag {};
struct output_iterator_tag {};
struct forward_iterator_ta {};
struct bidirectional_iterator_tag {};
struct random_access_iterator_tag {};
```

用来表示迭代器的类型，这是一个函数，在traits中声明如下

```C++
template <class I>
struct iterator_traits {
    ...
    typedef typename I::iterator_category iterator_category;
};

template <class T>
struct iterator_traits<T *> {
    ...
    // 原生指针的迭代器是一种Random Access Iterator
    typedef random_access_iterator_tag iterator_category;
};

template <class T>
struct iterator_traits<const T *> {
    ...
    typedef random_access_iterator_tag iterator_category;
};
```

## __type_traits

SGI将`iterator_traits`延伸到了迭代器之外，创造了`__type_traits`，**双底线表示这是SGI STL内部所用，不在STL规范之内**

`__type_traits`负责萃取类型的特性，比如这个类是否具有`non-trivail default ctor`，是否具有`non-trivial copy ctor`，是否具有`non-trivial assignment operator`，是否具有`non-trivial dtor`，便于判断是否选择已有的构造，或者通过`malloc()`、`memcpy()`等操作

```c++
__type_traits<T>::has_trivial_default_constuctor;
__type_traits<T>::has_trivial_copy_constuctor;
__type_traits<T>::has_trivial_assignment_operator;
__type_traits<T>::has_trivial_destructor;
__type_traits<T>::is_POD_type;
```

因为需要使用这些值进行参数推导，**而编译器只有面对类对象的参数时，才能进行参数推导**，所以需要将返回结果设定为有真假性质的对象

```c++
struct __true_type {};
struct __false_type {};
```

为了实现萃取效果，`__type_traits`内定义了一些typedef，其值不是`__true_type`就是`__false_type`

```c++
template <class type>
struct __type_traits {
    // 这是为了通知有能力自动将__type_traits特化的编译器，这是一个特殊的__type_traits template
    typedef __true_type this_dummy_member_must_be_first; 
    
    // 可以重新排列以下的成员次序
    // 可以移除以下的任何成员
    // 不可以将以下成员重新命名而没有改变编译器中对应的名称
    // 新加入的成员被视为一般成员，需要在编译器中加上适当支持
    typedef __false_type has_trivial_default_constuctor;
    typedef __false_type has_trivial_copy_constuctor;
    typedef __false_type has_trivial_assignment_operator;
    typedef __false_type has_trivial_destructor;
    typedef __false_type is_POD_type;
};
```
