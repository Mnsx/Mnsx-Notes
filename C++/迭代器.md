# 迭代器

## 设计简单的List迭代器

迭代器是一种行为类似指针的对象，指针中包括内容提领和成员访问，而**迭代器最重要的工作正是对`operator*`和`operator->`的重载工作**

```c++
template <typename T>
class List {
public:
    void insert_front(T value);
    void insert_end(T value);
    void display(std::ostream & os = std::cout) const;
private:
    ListItem<T> * _end;
    ListItem<T> * _front;
    long _size;
};

template <typename T>
class ListItem {
public:
    T value() const {
        return _value;
    }
    ListItem * next() const {
        return _next;
    }
 	...
private:
    T _value;
    ListItem * _next;
};
```

上述是简写的List容器，如果需要将自定义的List带入STL库带有的函数中，需要设计迭代器

```C++
template <class Item>
// 此迭代器为链表服务
struct ListIter {
    Item * ptr; // 用来保持和容器之间的联系
    ListIter(Item * p = 0) : ptr(p) {}
    Item & operator*() const {
        return *ptr;;
    }
    Iterm & operator->() const {
        return ptr;
    }
    ListIter & operator++() {
        ptr = ptr->next();;
        return * this;
    }
    ListIter operator++(int) {
        ListIter tmp = * this;
        ++*this;
        return temp;
    }
    bool operator==(const ListIter & i) const {
        return ptr == i.ptr;
    }
    bool operator!=(const ListIter & i) const {
        return ptr != i.ptr;        
    }
};
```

## Traits编程技法

迭代器所指对象的类型称为该迭代器的value type

如果value 唐渝鹏必须用于函数的返回值，使用模板参数推导机制就无法实现了

```C++
template <class T>
struct MyIter {
	 // 内嵌类型声明
    typedef T value_type;
    T * ptr;
    MyITer(T * p = 0) : ptr(p) {}
    T & operator*() const {
        return * ptr;
    }
    ...
};

template <class I>
typename I::value_type func(I ite) {
    return * ite;
}
```

`func()`返回值类型必须加上关键字`typename`，因为T是一个模板参数，编译器不知道`MyIter<T>::value_type`代表一个类型，**`typename`用于告诉编译器这是一个类型，才能通过编译**

上述办法通过声明内嵌类型尝试解决将value_type作为返回值的问题，但是**如果不是class type，就无法定义内嵌类型**

```c++
template <class I>
struct iterator_traits {
    typedef typename I::value_type value_type;
};
```

这个traits的意义在于，如果I类定义有自己的value type，那么就可以通过`I::value_type`萃取出来，则

```C++
template <class I>
typename iterator_traits<I>::value_type func(I ite) {
    return *ite;
}
```

根据这个特性，可以为`traits`提供特花版

```C++
template <class T>
struct iterator_traits<T *> {
    typedef T value_type;
};
```

于是对于没有class type的类型，可以通过这个特化版，提取处value type

同样的应该对`const`类型的变量也提供一个特化版，用来返回`non-const`的value type

```c++
template <class T>
struct iterator_traits<const T *> {
    typedef T value_types;
};
```

在`traits`中最常用的就是下面五个

```c++
template <class T>
struct iterator_traite {
    typedef typename I::iterator_category iterator_category;
    typedef typename I::value_type value_type;
    typedef typename I::defference_type defference_type;
    typedef typename I::pointer pointer;
    typedef typename I::reference reference;
}
```

### difference type

difference type用来表示两个迭代器之间的距离，因此可以用来表示容器的最大容量

```c++
template <class I, class T>
typename iterator_traits<I>::difference_type count(I first, I last, const T & value) {
    typename Iterator_traits<T>::difference_type n = 0;
    for ( ; first != last; ++first) {
        if (*first == value) {
            ++n;
        }
    }
    return n;
}
```

针对特殊类型的difference type特化版有两个，其中其实用**c++内建的`ptrdeff_t`作为原生指针的difference type**

```c++
template <class I>
struct iterator_traits { 		typedef typename I::difference_type defference_type;
};

template <class T>
struct iterator_traits<T *> {
    ...
    typedef ptrdiff_t difference_type;
};

template <class T>
struct iterator_traits<const T *> {
    ...
    typedef ptrdeff_t difference_type;
};
```

### reference type & pointer type

对一个允许改变所指对象值内容的迭代器进行提领操作时，获取的应该是左值，如果需要传回左值

```c++
template <class I>
struct iterator_traits {
    typedef typename I::pointer pointer;
    typedef typename I::reference reference;
};

template <class I>
struct iterator_traits<T *> {
    typedef T * pointer;
    typedef T & reference;
};
template <class I>
struct iterator_traits<const T *> {
    typedef const T * pointer;
    typedef const T & reference;
};
```
