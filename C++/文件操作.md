# 文件操作

## 概述

### 流和缓冲区

C++程序把输入和输出看作字节流，输入时，程序从输入流中抽取字节，输出时，程序将字节插入到输出流中

通过使用缓冲区可以更高效的处理输入和输出，缓冲区时用作中介的内存块，它是将信息从设备传输到程序或从程序传输给设备的临时存储工具

* `streambuf`类为缓冲区提供了内存，并提供了用于填充缓冲区、访问缓冲区内容、刷新缓冲区和管理缓冲区内存的类方法
* `ios_base`类表示流的一般特征，如是否可读取、是否二进制流还是文本流
* `ostream`类是从ios类派生而来的，提供了输出方法
* `istream`类也是从ios类派生而来，提供了输入方法
* `iostream`类是基于istream和ostream类的，因此继承了输入方法和输出方法

iostream类库自动创建8个流对象（4个用于窄字符流，4个用于宽字符流）

* `cin`对象对应于标准输入流，默认情况下，这个流被关联到标准输入设备，wcin类似用于处理wchar_t类型
* `cout`对象与标准输入流相对应，默认情况下，这个流被关联到标准输出设备，wcout类似用于处理wchat_t类型
* `cerr`对象与标准错误流相对应，用于显示错误信息，默认情况下，这个流被关联到标准输出设备，**这个流没有被缓冲，意味着信息将被直接发送到屏幕，而不会等到缓冲区填满或新的换行符**，wcerr对象类似处理wchat_t类型
* `clog`对象也是标准错误流，默认情况下，这个流被关联到标准输出设备，**这个流被缓冲**，wclog对象类似处理wchat_t类型

## cout

ostream类最重要的任务之一是将数值类型转换为以文本形式表示的字符流，将数据内部表示（二级制位模式）转换为由字符字节组成的输出流

除了<<重定向运算符，ostream还提供了`put()`方法和`write()`方法，前者用于显示字符，后者用于显示字符串

### 刷新输出缓冲区

对屏幕输出，填充缓冲区的重要性低很多，可以通过使用两个控制符中的一个来强制进行刷新，控制符`flush`刷新缓冲区，而控制符`endl`刷新缓冲区并插入一个换行符

### 格式化

ostream插入运算符将值转换位文本格式，默认情况下，格式化值的方式如下

* 对于char值，如果代表可打印字符，则将被作为一个字符显示在宽度位一个字符的字段中
* 对于数值整型，将以十进制方式显示在一个刚好容纳数字及负号的字段中
* 字符串被显示在宽度等于该字符串长度的字段中
* 浮点类型被现实位6位，末尾的0不显示（**显示的数字位数与数字被存储时精度没关系**），数字将以定点表示法显示还是以科学计数法表示，取决于他的值，**当指数大于等于6或小于等于-5时，将使用科学计数法表示**

**修改显示时使用的计数系统**

要控制整数通过十进制、十六机制还是八进制显示，可以使用dec、hex和oct控制符

**调整字段宽度**

可以使用width成员函数将长度不同的数字放到宽度相同的字段中

```c++
int width();
int width(int i);
```

第一种格式返回字段宽度的当前设置

第二种格式将字段宽度设置位i个空格，并返回以前的字段宽度值

**填充字符**

可以使用fill成员函数来改变填充字符

**设置浮点数的显示精度**

默认模式下，它指的是显示的总位数，定点模式和科学模式下，精度指的是小数点后的位数

C++的默认精度为6位，通过使用precision成员函数可以选择其他值

**打印末尾的0和小数点**

ios_base类提供了setf函数，能够控制多种格式化特性，这个类设置了多个常量，可以用作该函数的参数

| 常量                | 含义                                    |
| ------------------- | --------------------------------------- |
| ios_base::boolalpha | 输入和输出bool值，可以为true或false     |
| ios_base::showbase  | 对于输出，使用C++基数前缀               |
| ios_base::showpoint | 显示末尾的小数点                        |
| ios_base::uppercase | 对于十六进制输出，使用大写字母，E表示法 |
| ios_base::showpos   | 在正数前面加上+                         |

还有两个参数的setf函数

| 第二参数              | 第一参数             | 含义                           |
| --------------------- | -------------------- | ------------------------------ |
| ios_base::basefield   | ios_base::dec        | 使用基数10                     |
|                       | ios_base::oct        | 使用基数8                      |
|                       | ios_base::hex        | 使用基数16                     |
| ios_base::floatfield  | ios_base::fixed      | 使用定点计数法                 |
|                       | ios_base::scientific | 使用科学计数法                 |
| ios_base::adjustfield | ios_base::left       | 使用左对齐                     |
|                       | ios_base::right      | 使用右对齐                     |
|                       | ios_base::internal   | 符号或基数前缀左对齐，值右对齐 |

## cin

### cin输入检查

跳过空白（空格、换行符和制表符），直到遇到非空白字符

### 流状态

流状态（被定义为iostate类型，而iostate是一种bitmask类型）由3个ios_base元素组成：`eofbit`、`badbit`或`failbit`，其中每个元素都是一位文件末尾设置为eofbit，如果是I/O错误返回failbit，可能还会存在无法诊断的失败破坏流则设置为badbit

| 成员                    | 含义                                                         |
| ----------------------- | ------------------------------------------------------------ |
| good()                  | 如果流可以使用，返回true                                     |
| eof()                   | 如果eof被设置，返回true                                      |
| bad()                   | 如果bad被设置，返回true                                      |
| fail()                  | 如果bad或fial被设置，返回true                                |
| rdstate()               | 返回流状态                                                   |
| exceptioins()           | 返回一个位掩码，指出那些标记异常被引发                       |
| exceptions(iosstate ex) | 设置将导致clear发生一场的状态                                |
| clear(iostate s)        | 将流状态设置为是s，s的默认值为0                              |
| setstate(iostate s)     | 调用clear(rdstate() \| s)，将设置与s中设置的位对应的流状态位，其他流状态位保持不变 |
