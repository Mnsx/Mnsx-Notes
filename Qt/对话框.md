### QFileDialog

```c++
String QFileDialog::getOpenFileName (QWidget *parent = nullptr,

                                     const QString &caption = QString(), 
                                     const QString &dir = QString(),
                                     const QString &filter = QString(), 
                                     QString *selectedFilter = nuliptr,
                                     QFileDialog::Options options = Options ());
```

parent是对话框的父窗口，一般设置为调用对话框的窗口对象

caption是对话框的标题

dir是打开对话框时的初始目录，通过`QDir::currentPath()`获取当前目录

filter是文件过滤器，设置选择不同后缀的文件，可以设置多组文件

selectedFilter是选择的文件过滤器，返回值表示选择文件时i使用的文件过滤器

option是对话框选项，是枚举类型`QFileDialog::Option`

* `QFileDialog::ShowDirsOnly`：只显示目录，默认是显示目录和文件夹
* `QFileDialog::DontConfirmOverwrite`：覆盖一个已经村咋的文件时不提示
* `QFileDialog::ReadOnly`：对话框的文件系统只读

```c++
                                      QString *selectedFilter = nullptr,

```

### QProgressDialog

用于显示进度的对话框，可以在循环操作中显示操作进度，需要创建一个对话框然后显示，并且在操作进度显示过程中不断刷新对话框上的进度条

```C++
QProgressDialog(const QString &labelText, 
                const QString &cancelButtonText, 
                int minimum,
                int maximum, 
                QWidget *parent = nullptr, 
                Qt::WindowFlags f = Qt::WindowFlags())
```

labelText是信息标签显示的文字

cancelButtonText是显示取消的按钮的标签

minimum和maximum分别是进度条的最大值和最小值

paretn是父窗口对象

f是窗口标志，有默认值

QProgressDialog主要接口功能如下

* `setAUtoReset(bool)`：若设置为true，当进度条的值达到最大值时将自动调用函数reset
* `setAutoClose(bool)`：若设置为true，运行reset时对话框将自动隐藏
* `setValue(int)`：为对话康上的进度条设置一个值，设置后进度条会自动刷新显示
* `reset()`：使进度对话框复位，如果autoClose为true，将隐藏
* `cancel()`：使对话框取消，会触发canceled喜好，并且wasCanceled函数返回true
* `wasCanceled()`：如果调用函数cancel或点击取消按钮，则返回true

## 自定义对话框

自定义对话框一般从QDialog类继承

### QDialog

新属性，`modal`和`sizeGripEnabled`，属性都是bool类型

`modal`表示是否需要模态方式显示，**函数show会阻塞运行**

`sizeGripEnabled`表示对话框右下角是否显示一个用于调整窗口大小的标记

函数`QWidget::show()`，显示一个对话框，一般show以非模态方式显示，这样对话框可以和主窗口进行交互

函数`QDialog::exec()`，对话框总是模态形式显示，并且有返回值，可以获取对话操作结果，返回值为枚举类`QDialog::DialogCode`

* `QDialog::Accepted`，值为1
* `QDialog::Rejected`，值为0

**QDialog定义了三个公共槽**

```c++
void QDialog::accept(); // 设置exec返回accepted，触发accepted信号
void QDialog::reject(); // 同理，rejected
void QDialog::done(int r); // 返回r，触发fnished信号
```
