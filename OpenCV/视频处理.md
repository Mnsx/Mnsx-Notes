## 视频处理

### 视频采集

* **摄像头采集**

  ```c++
  CV_WRAP explicit VideoCapture(int index, int apiPreference = CAP_ANY);
  ```

  用来采集视频的对象

  `int index`：摄像头的编号

  `int apiPreference`：平台对应的api，默认使用0，自动根据平台判断

  ```c++
  CV_WRAP virtual bool read(OutputArray image);
  ```

  采集的接口

  `OutputArray image`：装载结果的数据类型，可以使用Mat

  ```c++
  CV_WRAP virtual void release();
  ```

  使用结束后应该主动释放视频采集对象

  **实例代码**

  ```c++
  void VideoCaptureTest1() {
      // 创建窗口显示
      cv::namedWindow("video", cv::WINDOW_AUTOSIZE);
      // 创建视频采集对象
      auto vc1 = cv::VideoCapture(0, cv::CAP_ANY);
      // 死循环从摄像头采集数据
      while (true) {
          // 使用Mat作为视频载体
          cv::Mat m;
          // 读取一帧数据
          bool res = vc1.read(m);
          if (res == false) {
              break;
          }
          // 将数据展示在窗口中
          cv::imshow("video", m);
          // 设置q作为退出按钮
          int key = cv::waitKey(10);
          if ((key & 0xFF) == 113) {
              break;
          }
      }
      // 释放视频采集器资源
      vc1.release();
      // 释放所有新建窗口
      cv::destroyAllWindows();
      return 0;
  }
  ```

* **媒体文件采集**

  ```c++
  CV_WRAP explicit VideoCapture(const String& filename, int apiPreference = CAP_ANY);
  ```

  从媒体文件中采集视频帧

  `const String& filename`：媒体文件路径

  `int apiPreference`：平台对应的api，默认使用0，自动根据平台判断

### 视频录制

```c++
CV_WRAP VideoWriter(const String& filename, int fourcc, double fps,
                    Size frameSize, bool isColor = true);
```

将视频帧转换成媒体文件

`const String& filename`：输出的文件名称

`int fourcc`：指定编码器的类型

`double fps`：视频的帧数

`Size frameSize`：视频的分辨率

`bool isColor`：生成的视频是否有颜色

```c++
CV_WRAP virtual void write(InputArray image);
```

将视频容器中的视频帧写入到VideoWriter中

`InputArray image`：需要被写入的视频帧容器，可以使用Mat

**实例代码**

```c++
void VideoWriterTest() {
    cv::namedWindow("video", cv::WINDOW_AUTOSIZE);
    auto vc1 = cv::VideoCapture(0, cv::CAP_ANY);

    // 创建编码器类型
    int fourccWin = cv::VideoWriter::fourcc('m', 'p', '4', 'v');
    // 创建视频写出对象
    auto vw1 = cv::VideoWriter("./test1.mp4", fourccWin, 30.0, cv::Size(1280, 720));

    // 判断摄像头是否为打开
    while (vc1.isOpened() == true) {
        cv::Mat m;
        bool res = vc1.read(m);
        if (res == false) {
            break;
        }

        cv::imshow("video", m);

        // 将采集视频输出
        vw1.write(m);

        int key = cv::waitKey(10);
        if ((key & 0xFF) == 113) {
            break;
        }
    }

    vc1.release();
    cv::destroyAllWindows();
    // 释放视频写入对象资源
    vw1.release();

    return 0;
}

```
