## 图像操作

### 图像融合

**图像运算就是矩阵运算**

```c++
CV_EXPORTS_W void addWeighted(InputArray src1, double alpha, InputArray src2,
                              double beta, double gamma, OutputArray dst, int dtype = -1);
```

根据权重将两个图片进行加

`InputArray src1`和`InputArray src2`：两个输入的资源

`double alpha`和`double beta`：分别对应两个资源的融合占比权重

`double gamma`：在两个融合后会再加上这个值

`OutputArray dst`：输出的资源

### 图像位运算

**位运算就是矩阵中的每个元素进行位运算**

* **非运算**

  ```c++
  CV_EXPORTS_W void bitwise_not(InputArray src, OutputArray dst,
                                InputArray mask = noArray());
  ```

* **与运算**

  ```c++
  CV_EXPORTS_W void bitwise_and(InputArray src1, InputArray src2,
                                OutputArray dst, InputArray mask = noArray());
  ```

* **或运算**

  ```c++
  CV_EXPORTS_W void bitwise_or(InputArray src1, InputArray src2,
                               OutputArray dst, InputArray mask = noArray());
  ```

* **异或运算**

  ```c++
  CV_EXPORTS_W void bitwise_xor(InputArray src1, InputArray src2,
                                OutputArray dst, InputArray mask = noArray());
  ```

**实例代码**

```c++
int bitwiseTest() {
    cv::Mat black = cv::Mat::zeros(cv::Size(200, 200), CV_8UC3);
    cv::Mat black1 = cv::Mat::zeros(cv::Size(200, 200), CV_8UC3);
    cv::rectangle(black, cv::Point(20, 20), cv::Point(120, 120), cv::Scalar(255, 255, 255), cv::FILLED);
    cv::imshow("black", black);
    cv::rectangle(black1, cv::Point(80, 80), cv::Point(180, 180), cv::Scalar(255, 255, 255), cv::FILLED);
    cv::imshow("black1", black1);

    // 与运算
    cv::Mat blackAnd;
    cv::bitwise_and(black, black1, blackAnd);
    cv::imshow("black and", blackAnd);

    // 非运算
    cv::Mat blackNot;
    cv::bitwise_not(black, blackNot);
    cv::imshow("black not", blackNot);

    // 或运算
    cv::Mat blackOr;
    cv::bitwise_or(black, black1, blackOr);
    cv::imshow("black or", blackOr);

    // 异或运算
    cv::Mat blackXor;
    cv::bitwise_xor(black, black1, blackXor);
    cv::imshow("black xor", blackXor); 

    cv::waitKey(0);

    return 0;
}
```

### 图像缩放

**核心函数**

```c++
cv::resize(src, dst, dsize, fx, fy, interpolation);
```

src表示输入图像、dst表示输出图像、dsize表示目标尺寸、fx和fy表示缩放比例、interpolation表示插值算法

**插值算法**

* **INTER_NEAREST（最近邻）**

  原理是直接取最近像素

  特点最快、质量最差、会出现明显马赛克

* **INTER_LINEAR（默认）**

  原理是双线性插值

  特点速度快、效果较好、最常用

* **INTER_CUBIC（三次插值）**

  特点效果更平滑、比linear清晰、更慢

* **INTER_AREA（缩小时推荐）**

  特点缩小时效果最好，抗锯齿好

**宽高比**

正常应该保持宽高比进行缩放

### 图像翻转

```c++
CV_EXPORTS_W void flip(InputArray src, OutputArray dst, int flipCode);
```

`int flipCode`：翻转的方向

* flipCode == 0 上下
* flipCode > 0 左右
* flipCode < 0 上下+左右

### 图像旋转

```c++
CV_EXPORTS_W void rotate(InputArray src, OutputArray dst, int rotateCode);
```

`int rotateCode`：旋转的方向

* ROTATE_90_CLOCKWISE 顺时针90deg
* ROTATE_180 180deg
* ROTATE_90_COUNTERCLOCKWISE 逆时针90deg

### 图像仿射变换

**仿射变换就是图像旋转、缩放、平移的总称**

```c++
CV_EXPORTS_W void warpAffine( InputArray src, OutputArray dst,
                             InputArray M, Size dsize,
                             int flags = INTER_LINEAR,
                             int borderMode = BORDER_CONSTANT,
                             const Scalar& borderValue = Scalar());
```

`InputArray M`：仿射变换矩阵

`Size dsize`：输出尺寸大小

`int flags`：插值算法

`int borderMode`：边界外推法标志

`const Scalar& borderValue`：填充边界的值

**变换矩阵**

```c++
inline
Mat getRotationMatrix2D(Point2f center, double angle, double scale)
{
    return Mat(getRotationMatrix2D_(center, angle, scale), true);
}

CV_EXPORTS Matx23d getRotationMatrix2D_(Point2f center, double angle, double scale);
```

`Point2f center`：中心点

`double angle`：旋转角度（逆时针）

`double scale`：缩放比例

```c++
CV_EXPORTS Mat getAffineTransform( const Point2f src[], const Point2f dst[] );
```

`const Point2f src[]`：三个坐标点的起始位置

`const Point2f dst[]`：三个坐标点的终止位置

**示例代码**

```c++
int main() {
    cv::VideoCapture cap(0, cv::CAP_ANY);
    if (!cap.isOpened()) {
        std::cout << "Error opening video stream or file" << std::endl;
        return -1;
    }

    cv::Mat frame;
    cap >> frame;
    if (frame.empty()) {
        std::cout << "Error reading frame" << std::endl;
        return -1;
    }
    cv::imshow("origin frame", frame);

    // 仿射
    // 手动生成变换矩阵
    cv::Mat m = cv::Mat_<float>({1.0f, 0.0f, 100.0f, 0.0f, 1.0f, 0.0f}).reshape(1, 2);
    // 使用getRotationMatrix2D生成变换矩阵
    cv::Mat m = cv::getRotationMatrix2D(cv::Point2f(0.0f, 0.0f), 15, 1.0);
    // 使用getAffineTransform生成变换矩阵
    std::vector<cv::Point2f> src{cv::Point2f(0, 0), cv::Point2f(1, 1), cv::Point2f(2, 2)};
    std::vector<cv::Point2f> dst{cv::Point2f(1, 1), cv::Point2f(2, 2), cv::Point2f(3, 3)};
    cv::Mat m = cv::getAffineTransform(src, dst);
    cv::Mat frameWarp;
    cv::warpAffine(frame, frameWarp, m, cv::Size(frame.cols, frame.rows));
    cv::imshow("warpAffine", frameWarp);

    cv::waitKey(0);

    return 0;
}
```
