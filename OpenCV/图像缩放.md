## 图像操作

### 图像融合

**图像运算就是矩阵运算**

```c++
CV_EXPORTS_W void addWeighted(InputArray src1, double alpha, InputArray src2,
                              double beta, double gamma, OutputArray dst, int dtype = -1);
```

根据权重将两个图片进行加

`InputArray src1`和`InputArray src2`：两个输入的资源

`double alpha`和`double beta`：分别对应两个资源的融合占比权重

`double gamma`：在两个融合后会再加上这个值

`OutputArray dst`：输出的资源

### 图像位运算

**位运算就是矩阵中的每个元素进行位运算**

* **非运算**

  ```c++
  CV_EXPORTS_W void bitwise_not(InputArray src, OutputArray dst,
                                InputArray mask = noArray());
  ```

* **与运算**

  ```c++
  CV_EXPORTS_W void bitwise_and(InputArray src1, InputArray src2,
                                OutputArray dst, InputArray mask = noArray());
  ```

### 图像缩放

**核心函数**

```c++
cv::resize(src, dst, dsize, fx, fy, interpolation);
```

src表示输入图像、dst表示输出图像、dsize表示目标尺寸、fx和fy表示缩放比例、interpolation表示插值算法

**插值算法**

* **INTER_NEAREST（最近邻）**

  原理是直接取最近像素

  特点最快、质量最差、会出现明显马赛克

* **INTER_LINEAR（默认）**

  原理是双线性插值

  特点速度快、效果较好、最常用

* **INTER_CUBIC（三次插值）**

  特点效果更平滑、比linear清晰、更慢

* **INTER_AREA（缩小时推荐）**

  特点缩小时效果最好，抗锯齿好

**宽高比**

正常应该保持宽高比进行缩放
