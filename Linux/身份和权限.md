# 身份和权限

## 用户身份

在Linux系统中，**UID是唯一的**，因此可以通过用户的UID来判断用户身份

> 管理员UID是0，系统的管理员用户
>
> 系统用户UID是1~999，Linux系统为了避免因某些服务程序出现漏洞而被黑客提权至整台服务器，**默认服务程序会有独立的系统用户负责运行**，进而有效控制被破坏范围
>
> 普通用户UID从1000开始，是由管理员创建的用于日常工作的用户

Linux系统创建每个用户时，**将自动创建一个与其同名的基本用户组**，而这个基本用户组只有该用户一个人，但是可以有多个扩展用户组

### 基本命令

* **id命令**

  用于显示用户详细信息

  ```shell
  # mnsx @ mnsx-archlinux in ~ [15:02:55] 
  $ id mnsx
  uid=1000(mnsx) gid=1000(mnsx) groups=1000(mnsx),998(wheel)
  ```

* **useradd命令**

  用于创建新的用户账户

  使用该命令创建用户账户时，**默认的用户家目录会被存放在`/home`目录中，默认的Shell解释器是`/bin/bash`，而且会默认创建一个与该用户同名的基本用户组**

  | 参数 | 作用                             |
  | ---- | -------------------------------- |
  | -d   | 指定用户家目录                   |
  | -e   | 账户的到期时间，格式为YYYY-MM-DD |
  | -u   | 指定该用户的默认UID              |
  | -g   | 指定一个初始的用户基本组         |
  | -G   | 指定一个或多个扩展用户组         |
  | -N   | 不创建与用户同名的基本用户组     |
  | -s   | 指定该用户的默认Shell解释器      |

  ```shell
  # mnsx @ mnsx-archlinux in ~ [15:03:06] C:130
  $ sudo useradd test
  
  # mnsx @ mnsx-archlinux in ~ [15:07:06] 
  $ id test
  uid=1001(test) gid=1001(test) groups=1001(test)
  ```

* **groupadd命令**

  用于创建新的用户组

  ```shell
  # mnsx @ mnsx-archlinux in ~ [15:08:48] C:10
  $ sudo groupadd testGroup
  ```

* **usermod命令**

  用于修改用户的属性

  | 参数  | 作用                                                         |
  | ----- | ------------------------------------------------------------ |
  | -c    | 填写用户账号的备注信息                                       |
  | -d -m | 参数-m与参数-d连用，可重新指定用户的家目录并将旧的数据转移过去 |
  | -e    | 账户的到期时间，格式为YYYY-MM-DD                             |
  | -g    | 变更所属用户组                                               |
  | -G    | 变更扩展用户组                                               |
  | -L    | 锁定用户禁止其登录系统                                       |
  | -U    | 解锁用户，允许其登录系统                                     |
  | -s    | 变更默认终端                                                 |
  | -u    | 修改用户的UID                                                |

  ```shell
  # mnsx @ mnsx-archlinux in ~ [15:08:55] 
  $ sudo usermod -e 2026-3-18 test
  ```

* **passwd命令**

  用于修改用户的密码、过期时间等信息

  | 参数    | 作用                                                   |
  | ------- | ------------------------------------------------------ |
  | -l      | 锁定用户，禁止其登录                                   |
  | -u      | 接触锁定，允许用户登录                                 |
  | --stdin | 允许通过标准输入修改用户密码                           |
  | -d      | 使该用户客户用空密码登录系统                           |
  | -e      | 强制用户在喜爱此登录时修改密码                         |
  | -S      | 显示用户的密码是否被锁定，以及密码所采用的加密算法名称 |

  ```shell
  # mnsx @ mnsx-archlinux in ~ [15:15:28] 
  $ sudo passwd -d mnsx
  passwd: password changed.
  ```

* **userdel命令**

  命令用于删除已有的用户账户

  | 参数 | 作用                     |
  | ---- | ------------------------ |
  | -f   | 强制删除用户             |
  | -r   | 同时删除用户及用户家目录 |

  ```shell
  # mnsx @ mnsx-archlinux in ~ [15:17:56] 
  $ sudo userdel -rf test
  userdel: test mail spool (/var/spool/mail/test) not found
  userdel: test home directory (/home/test) not found
  ```

## 文件权限

```shell
# mnsx @ mnsx-archlinux in ~ [15:19:20] 
$ ll
total 0
drwxr-xr-x 1 mnsx mnsx  48 Mar 12 09:23 Applications
drwxr-xr-x 1 mnsx mnsx  56 Mar 16 13:30 Documents
```

* 第一位是文件类型，普通文件（-）、目录文件（d）、链接文件（l）、管道文件（p）、块设备文件（b）以及字符设备文件（c）
* 第二位是访问权限，访问权限的顺序是，文件所属者，文件所属组，其他用户
* 第三位是所属用户
* 第四位是所属用户组
* 第五位是占用的磁盘大小
* 第六位是最后修改时间
* 第七位是文件信息等信息

## 文件特殊权限

* **SUID**

  是一种对二进制程序进行设置的特殊权限，能够让二进制程序的执行者临时拥有所属用户的权限

* **SGID**

  当对二进制程序进行设置时，能够让执行者临时获取到文件所属组的权限，而对目录进行设置时，则是让目录内新创建的文件自动继承该目录原有用户组的名称

* **SBIT**

  SBIT特殊权限位可确保用户只能删除自己的文件，而不能删除其他用户的文件

`chmod`命令设置特殊权限时参数如下

| 参数 | 作用         |
| ---- | ------------ |
| u+s  | 设置SUID权限 |
| u-s  | 取消SUID权限 |
| g+s  | 设置GUID权限 |
| g-s  | 取消GUID权限 |
| o+t  | 设置SBIT权限 |
| o-t  | 取消SBIT权限 |

## 文件隐藏属性

隐藏属性专用的设置命令是`chattr`，专用的查看命令是`lsattr`

* **chattr命令**

  用于设置文件的隐藏权限

  | 参数 | 作用                                                         |
  | ---- | ------------------------------------------------------------ |
  | i    | 无法对文件进行修改，若对目录设置了该参数，则仅能修改其中的子文件内容而不能新建或删除文件 |
  | a    | 仅允许追加内容，无法覆盖/删除内容                            |
  | S    | 文件内容在变更后立即同步到硬盘                               |
  | s    | 测地从硬盘中删除，不可恢复                                   |
  | A    | 不再修改这个文件或目录的最后访问时间                         |
  | b    | 不再修改文件或目录的存取时间                                 |
  | D    | 检查压缩文件中的错误                                         |
  | d    | 使用dump命令备份时忽略本文件/目录                            |
  | c    | 默认将文件或目录进行压缩                                     |
  | u    | 当删除该文件后依然保留其在硬盘中的数据，方便恢复             |
  | t    | 让文件系统支持尾部合并                                       |
  | x    | 可以直接访问压缩文件中的内容                                 |

  ```shell
  # mnsx @ mnsx-archlinux in ~ [15:55:03] 
  $ sudo chattr +a 1.txt 
  
  # mnsx @ mnsx-archlinux in ~ [15:55:12] 
  $ rm -rf 1.txt 
  rm: cannot remove '1.txt': Operation not permitted
  ```

* **lsattr命令**

  用于查看文件的隐藏权限

## 文件访问控制列表

基于普通文件或目录设置ACL访问控制就是针对指定的用户或目录的操作权限

* **setfacl命令**

  用于管理文件的ACL权限规则

  | 参数 | 作用             |
  | ---- | ---------------- |
  | -m   | 修改权限         |
  | -M   | 从文件中读取权限 |
  | -x   | 删除某个权限     |
  | -b   | 删除全部权限     |
  | -R   | 递归子目录       |

  ```shell
  # mnsx @ mnsx-archlinux in ~ [16:01:54] C:2
  $ sudo setfacl -Rm u:mnsx:rwx /root
  
  # mnsx @ mnsx-archlinux in ~ [16:02:29] 
  $ ls -ld /root
  drwxrwx---+ 1 root root 100 Mar 12 11:17 /root
  ```

  访问权限的最后一位从`.`变成了`+`

* **getfacl命令**

  用于查看文件的ACL权限规则

  > 备份文件的ACL，并恢复
  >
  > ```shell
  > getfacl -R /home > backup.acl
  > 
  > setfacl --restore backup.acl
  > ```

## su命令和sudo服务

`su`可以在不退出的情况下切换用户

`sudo`命令用于给普通用户提供额外的权限

| 参数           | 作用                                                   |
| -------------- | ------------------------------------------------------ |
| -h             | 列出帮助信息                                           |
| -l             | 列出当前用户可执行的命令                               |
| -u 用户名或UID | 以指定的用户身份执行命令                               |
| -k             | 清空密码的有效时间，下次执行sudo时需要再次进行密码验证 |
| -b             | 在后台执行指定命令                                     |
| -p             | 更改询问密码的提示语                                   |
