# Shell脚本

## 快速上手

```shell
#!/bin/zsh
# 注释
pwd
ls -la
```

上述shell脚本中出现三种不同的元素

* 第一行的脚本声明（#!）用来告诉系统Shell解释器的名称
* 第二行的注释信息（#）是对脚本功能和某些命令的介绍信息
* 后续内容是可执行语句

```shell
#/bin/zsh
echo "当前脚本名称$0"
echo "总共有$#个参数，分别是$*"
echo "第一个参数是$1"
```

## 条件表达式

Shell脚本中的条件测试语句可以判断表达式是否成功，若条件成立则返回0,否则返回非零值，`[ 条件表达式 ]`

条件测试语句可以分为四种

* **文件测试语句**

  文件测试即使用指定条件来判断文件是否存在或权限是否满足等情况的运算符

  | 操作符 | 作用                       |
  | ------ | -------------------------- |
  | -d     | 测试文件是否为目录类型     |
  | -e     | 测试文件是否存在           |
  | -f     | 判断是否为一般文件         |
  | -r     | 测试当前用户是否有权限读取 |
  | -w     | 测试当前用户是否有权限写入 |
  | -x     | 判断当前用户是否有权限执行 |

  ```shell
  #!/bin/zsh
  [ -d /etc/fstabl ]
  echo $?
  ```

* 逻辑测试语句

  `&&`、`||`、`!`

* 整数值比较语句

  | 操作符 | 作用           |
  | ------ | -------------- |
  | -eq    | 是否等于       |
  | -ne    | 是否不等于     |
  | -gt    | 是否大于       |
  | -lt    | 是否小于       |
  | -le    | 是否小于或等于 |
  | -ge    | 是否大于或等于 |

* 字符串比较语句

  | 操作符 | 作用                   |
  | ------ | ---------------------- |
  | =      | 比较字符串内容是否相同 |
  | !=     | 比较字符串内容是否不同 |
  | -z     | 判断字符串内容是否为空 |

## if条件测试语句

if条件语句的单分支结构由`if`、`then`、`fi`

```shell
#!/bin/zsh
DIR="/etc"
if [ ! -d $DIR ]
then
	mkdir -p $DIR
fi
```

if条件语句的双分支结构由`if`、`then`、`else`、`fi`

```shell
#!/bin/zsh
ping -c -3 -i 0.2 -w 3 $1 &> /dev/null
if [ $? -eq 0 ]
then
	echo "Host $1 is On-line"
else
	echo "Host $1 is Off-line"
fi
```

if条件语句的多分支结构由`if`、`then`、`else`、`elif`、`fi`

```shell
#!/bin/zsh
read -p "Enter your score(0-100)" GRADE
if [ $GRADE -ge 85 ] && [ $GRADE -le 100 ]
then
	echo "$GRADE is e"
elif [ $GRADE -ge 70 ] && [ $GRADE -le 84 ]
then
	echo "$GRADE is b"
fi
```

## case条件测试语句

```shell
read -p "Enter a key: " KEY
case "$KEY" in
	[a-z][A-Z])
		...
		;;
	[0-9])
		...
		;;
	*)
		...
esac
```

## 定时任务

### 一次性定时任务

用`at`命令实现这种功能，只需要写成`at 时间`的形式，如果想要查看已设置好但未执行的一次性定时任务，可以用`at -l`命令，如果想要删除，可以使用`atrm 任务序列号`

| 参数 | 作用                   |
| ---- | ---------------------- |
| -f   | 执行包含命令的任务文件 |
| -q   | 指定新任务名称         |
| -l   | 显示待执行列表         |
| -d   | 删除指定待执行任务     |
| -m   | 任务执行后给用户发邮件 |

### 周期性定时任务

创建、编辑任务的命令为`crontab -e`，查看当前定时任务的命令是`crontab -l`，删除某条定时任务的命令`crontab -r`，如果使用管理员的身份，可以在`crontab -u`中编辑他人的定时任务

**分、时、日、月、星期**，如果有些字段没有被设置，则需要使用型号(*)占位
