# 硬盘管理

## 存储结构

下表是Linux系统中常见的目录名称以及相应内容

| 目录名称    | 应放置文件的内容                                          |
| ----------- | --------------------------------------------------------- |
| /boot       | 开机所需文件-内核、开机菜单以及所需配置文件等             |
| /dev        | 以文件形式存放任何设备和接口                              |
| /etc        | 配置文件                                                  |
| /home       | 用户主目录                                                |
| /bin        | 存放单用户模式下还可以操作的命令                          |
| /lib        | 开机时用到的函数库，以及/bin和/sbin下面的命令要调用的函数 |
| /sbin       | 开机过程中要使用的命令                                    |
| /media      | 用于挂在设备文件的目录                                    |
| /opt        | 放置第三方的软件                                          |
| /root       | 系统管理员的家目录                                        |
| /srv        | 一些网络服务的数据文件目录                                |
| /tmp        | 任何人均可使用的共享临时目录                              |
| /proc       | 虚拟文件系统，系统内核、进程、外部设备及网络状态等        |
| /usr/local  | 用户自行安装的软件                                        |
| /usr/sbin   | Linux系统开机时不会使用到的软件/命令/脚本                 |
| /usr/share  | 帮助和说明文件，也可放置共享文件                          |
| /var        | 主要存放经常变化的文件，如日志                            |
| /lost+found | 当文件系统发生错误时，将一些丢失的文件片段存放在这里      |

## 物理设备的命名规则

| 硬件设备      | 文件名称           |
| ------------- | ------------------ |
| IDE设备       | /dev/hd[a-d]       |
| SCSI/SATA/U盘 | /dev/sd[a-z]       |
| Virtio设备    | /dev/vd[a-z]       |
| 软驱          | /dev/fd[0-1]       |
| 打印机        | /dev/lp[0-15]      |
| 光驱          | /dev/cdrom         |
| 鼠标          | /dev/mouse         |
| 磁带机        | /dev/st0或/dev/ht0 |

硬盘分区主分区或扩展分区的编号从1开始，到4结束，逻辑分区从编号5开始

## 文件系统

Linux支持数十种文件系统，而最常见的文件系统如下

* **Ext2**：是Linux系统的第一个商业级文件系统，**但由于不包含日志读写功能，数据丢失的可能性很大**
* **Ext3**：是一款日志文件系统，**它会把整个硬盘的每个写入动作的细节都预先记录下来，然后再进行实际操作**，以便在发生异常宕机后能回溯到被中断的部分，但是当硬盘容量较大时，所需的修复时间也很长，而且不能完全保证数据不会丢失
* **Ext4**：**作为`RHEL6`系统中默认的文件管理系统**，它支持的存储容量高达1EB，而且能够有无限多的子目录，而且能批量分配块，从而极大提升读写效率
* **XFS**：是一种高性能的日志文件系统，而且是**`RHEL7/8`中默认的文件管理系统**，它的优势在于**快速回复可能被破坏的文件**，而且强大的日志功能只需花费极低的计算和存储性能，它最大支持存储容量为18EB

为了使用户在读取或写入文件时不用关心底层的硬盘结构，**Linux内核中的软件层为用户程序提供了一个虚拟文件系统（Virutal File System，VFS）接口**

## 挂载硬件设备

### mount命令

用于挂在文件系统，**一般不需要使用`-t`来指定文件系统的类型**，Linux系统会自动进行判断

| 参数 | 作用                                 |
| ---- | ------------------------------------ |
| -a   | 挂载所有在/etc/fstab中定义的文件系统 |
| -t   | 指定文件系统的类型                   |

```shell
# mnsx_x @ ZPIC-U9WR1U in ~ [22:44:42]
$ sudo mount /dev/sdb ./test
```

如果想要让硬件设备和目录永久的自动关联，就必须把挂在信息按照指定的填写格式写入`/etc/fstab`文件中

| 字段     | 意义                                                         |
| -------- | ------------------------------------------------------------ |
| 设备文件 | 一般为设备的路径+设备的名称，也可以写UUID                    |
| 挂载目录 | 指定要挂载到的目录，需在挂载前创建好                         |
| 格式类型 | 指定文件系统的格式                                           |
| 权限选项 | 若设置为default，则默认权限为rw、suid、dev、exec、auto、nouser、async |
| 是否备份 | 若为1则开机后使用dump进行磁盘备份                            |
| 是否自检 | 若为1则开机后自动进行磁盘自检                                |

### df命令

用于查看已挂载的磁盘使用情况，`df -h`

```shell
# mnsx_x @ ZPIC-U9WR1U in ~ [22:45:58]
$ df -h
Filesystem      Size  Used Avail Use% Mounted on
none            7.8G     0  7.8G   0% /usr/lib/modules/6.6.87.2-microsoft-standard-WSL2
none            7.8G  4.0K  7.8G   1% /mnt/wsl
drivers         300G  185G  116G  62% /usr/lib/wsl/drivers
```

### umount命令

用于取消关联的设备文件或挂载目录其中一项即可

```shell
# mnsx_x @ ZPIC-U9WR1U in ~ [22:55:28] C:32
$ sudo umount ./test
```
