## 系统工作命令

### echo命令

用于在终端设备中输出字符串或变量提取后的值

```shell
# mnsx @ mnsx-archlinux in ~/Documents/Notes on git:master x [15:59:34]
```

用于显示和设置系统的时间与日期


| %m   | 月份（1-12）               |
| %p   | 显示出AM或PM               |
| %a   | 缩写的工作日名称（Sun）    |
| %A   | 完整的工作日名称（Sunday） |
| %b   | 缩写的月份名称（Jan）      |
| %B   | 完整的月份名称（January）  |
| %q   | 季度（1-4）                |
| %y   | 简写的年份（20）           |
| %Y   | 完整的年份（2020）         |
| %d   | 本月中的第几天             |
| %j   | 今年中的第几天             |
| %n   | 换行符                     |

有五种常见的进程状态，分别为运行、中断、不可中断、僵死与停止

* **R（运行）**：进程正在运行或在运行队列中等待
* **S（中断）**：进程处于休眠中，当某个条件形成后或者接收到信号时，则脱离该状态
* **D（不可中断）**：进程不响应系统异步信号，即便用`kill`命令也不能将其中断
* **Z（僵死）**：进程已经终止，但进程描述符依然存在，直到父进程调用`wait4()`系统函数后将进程释放
* **T（停止）**：进程收到停止信号后停止运行

除了这五种常见的状态，还有可能是**高优先级（<）**,**低优先级（N）**，**被锁进内存（L）**，**包含子进程（s）**以及**多线程（I）**

### top命令

用于动态监控进程活动及系统负载等信息

1. 系统时间、运行时间、登录终端数、系统负载（分别为1分钟、5分钟、15分钟内的平均值）
2. 进程总数、运行中的进程数、睡眠中的进程数、停止的进程数、僵死的进程数
3. 用户占用资源百分比、系统内核占用资源百分比、改变过优先级的进程资源百分比、空闲的资源的百分比等
4. 物理内存总量、内存空闲量、内存使用量、作为内存缓存的内存量
5. 虚拟内存总量、虚拟内存空闲量、虚拟内存使用量、已被提前加载的内存量

### nice命令

用于调整进程的优先级

```shell
# mnsx @ mnsx-archlinux in ~/Documents/Notes on git:master x [16:11:17] 
$ nice -n 10 sleep 60
```

top中的PR和NI值代表进程的优先级，数字越低（-20到19），优先级越高


**主要是查看网卡名称、inet参数后面的IP地址，ether参数后面的网卡物理地址，以及RX、TX的接受数据包与发送数据包的个数以及基类流量**

### uname命令

用于查看系统内核版本与架构信息

```shell
# mnsx @ mnsx-archlinux in ~/Documents/Notes on git:master x [16:16:13] C:127
$ uname -a
Linux mnsx-archlinux 6.19.6-zen1-1-zen #1 ZEN SMP PREEMPT_DYNAMIC Wed, 04 Mar 2026 18:24:56 +0000 x86_64 GNU/Linux
```

通过`-a`查看系统的内核名称、主机名称、内核发行版本、节点名、压制时间、硬件名称、硬件平台、处理器类型以及操作系统名称等信息

### locate命令

用于按照名称快速搜索文件所对应的位置

```shell

```

locate命令是将一些常用的目录做成了一个索引库文件，一般叫作`/var/lib/mlocate/mlocate.db`

第一次使用需要先执行`updatedb`生成出索引数据库

| 参数  | 作用               |
| ----- | ------------------ |
